# مختبر فيزياء السادس — Vercel

المشروع جاهز للنشر كموقع Static على Vercel.

## النشر
1. ارفع محتويات هذا المجلد إلى GitHub repository.
2. في Vercel اختر **New Project** ثم المستودع.
3. Framework Preset: **Other**.
4. لا تحتاج Build Command.
5. Output Directory: اتركها فارغة.
6. اضغط Deploy.

الملف الرئيسي هو `index.html`، والتنقل داخل الموقع يعتمد على hash routes (`#/...`) لذلك لا يحتاج rewrites خاصة.
